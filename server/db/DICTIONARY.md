## 출처

**국립국어원 한국어기초사전** — https://krdict.korean.go.kr

초성배틀에 이게 결정적이다. 100만 개짜리 대사전을 그대로 쓰면 힌트만 보고
아무도 못 맞히는 문제가 나오는데, 등급이 있으면 "낼 수 있는 말"과 "인정만 하는
말"을 데이터가 알아서 갈라 준다.

| 구분 | 규모 | 근거 |
| --- | --- | --- |
| 표제어 전체 | 56,555 | 원본 |

### 표제어만 쓰는 이유

뜻풀이·예문·발음 음성·이미지는 **개방 대상이 아니다**. 출판물 인용이 섞여 있어
국립국어원도 재배포를 허용하지 않는다. 초성배틀에 필요한 건 "이 낱말이 사전에
있는가"뿐이라 표제어만 가져오고, 임포터도 표제어 외에는 저장하지 않는다.

## 받아서 넣기

```bash
# 1. 원본 받기 (로그인 불필요)
#    https://krdict.korean.go.kr/download/downloadPopup → 'XML 전체 내려받기'
# 2. 압축을 풀어 server/db/krdict/ 아래에 *.xml 을 둔다 (git에는 넣지 않는다)

cd server
npm run db:import -- --dry   # 무엇이 들어갈지 먼저 본다
npm run db:import            # 실제로 넣는다
npm run db:block             # 차단 목록만 다시 적용할 때
```

서버는 기동할 때 사전을 통째로 메모리에 올린다(NFR-1). 임포트 뒤에는 **서버를
다시 띄워야** 반영된다.

### 돌리는 순서

`db:seed`와 `db:import`는 순서에 상관없이, 몇 번을 돌려도 된다. 셋 다 출제 자격을
**올리기만 하고 내리지 않기** 때문이다(`is_curated = words.is_curated OR 새 값`).

내리는 길은 하나뿐이다 — 임포터가 마지막에 낮춤말·차단 목록을 명시적으로 내린다.
그래서 `db:import`를 마지막에 돌린 상태가 기준이다. 손으로 고른 시드에 있어도
낮춤말 동음이의어가 걸리면 거기서 빠진다(예: `축구`).

## 걸러내기

### 사전 → 게임

| 기준 | 결과 |
| --- | --- |
| 품사 = 명사 | 동사·형용사 기본형을 넣으면 '하다·되다·가다'가 수많은 힌트의 정답이 되어 라운드가 시시해진다 |
| 단위 = 단어 | 관용구·속담·문법 표현은 한 낱말이 아니다 |
| 2~4글자 완성형 한글 | FR-G1 |
| 등급 초급·중급 | 출제용. 고급·미지정은 판정에서만 인정한다 |

### 부적절어

사전은 말을 판단하지 않고 싣는다. 게임은 그럴 수 없다(전체 이용가, 앱인토스
검수). 다만 "곤란하다"에는 아주 다른 것들이 섞여 있다.

| | 예 | |
| --- | --- | --- |
| 낱말 자체가 욕 | 씨발·병신·개새끼 | 어떤 맥락에서도 남에게 보낼 이유가 없다 |
| 평범한데 뜻이 여럿 | 걸레·새끼·호구 | 걸레는 닦는 천이고 새끼는 동물의 아기다 |
| 중립적인데 주제가 무겁다 | 자살·마약·살인 | 뉴스와 교과서에 나오는 서술어다 |

한 칸에 몰아넣으면 멀쩡한 낱말이 사전에서 사라진다. 그래서 두 단계로 나눈다.

**출제 금지** (`is_curated = false`, 판정은 인정) — 대부분이 여기 온다.

- 사전이 뜻풀이에 `낮잡아`·`비속하게` 표시를 달아 둔 낱말 (295개, 출제 풀에서
  15개). 귀머거리·장님·바보처럼 이미 차별어로 표시된 말은 여기서 자동으로
  걸러지므로 손 목록에 따로 적지 않는다.
- `src/words/blocklist.js`의 `NOT_SERVED` — 자살·마약·성범죄처럼 사전이 아무
  표시도 달지 않는 것들. 낱말에 죄가 있는 게 아니라 파티 게임이 화면 한가운데
  띄우고 다 같이 맞힐 자리가 아니라는 뜻이다.

**완전 차단** (`status = 'BANNED'`, 출제·판정 모두 제외) — 아주 좁게 쓴다.

판정에서 인정하면 그 낱말이 정답 바에 실려 **방 전체 화면에 뜬다**(`round.won`).
즉 판정 인정은 곧 노출이고, 채팅이 없는 이 게임에서 욕설을 남에게 보낼 수 있는
유일한 통로가 된다. 그 통로를 막는 게 이 목록의 전부다. 노골적 욕설과 성기 속어
21개뿐이고, 그중 학습자 사전에 실제로 있는 건 5개다.

반대로 **사전에 있는 말을 판정에서 빼면 안 된다.** "없는 단어"라고 답하는 셈이라
대놓고 거짓말이고, 억울함을 막자고 판정 사전을 관대하게 만든 취지에도 어긋난다.

목록에서 뺀 낱말은 `npm run db:block`을 다시 돌리면 되살아난다. 신고로 막은
낱말(`source='REPORT'`)은 되살리지 않는다 — 사람이 보고 막은 것을 목록이
되돌리면 안 된다.

이 목록이 완전할 수는 없다. 놓친 말은 단어 신고(`word_reports`)로 받아 옮기는
게 원래 설계다(FR-W2).

판정 사전 최종 규모는 **114,781개** — 기초사전 27,400 + 우리말샘 77,696 + 위키데이터 9,685(인명 7,696 · 캐릭터 1,989).

## 우리말샘 (판정 전용)

**국립국어원 우리말샘** — https://opendict.korean.go.kr · 표제어 110만 · 같은
CC BY-SA 2.0 KR

기초사전과 역할이 다르다.

| | 등급 | 쓰임 |
| --- | --- | --- |
| 한국어기초사전 | 초급·중급·고급 | **출제** + 판정 |
| 우리말샘 | 없음 | **판정만** |

우리말샘은 전수 대사전이라 어휘 등급이 없다. 어떤 낱말이 "누구나 아는 말"인지
판단할 근거가 없으니 출제 풀에 넣을 수 없고, 넣으면 힌트만 보고 아무도 못 맞히는
문제가 나온다. 그래서 여기서 들어오는 낱말은 `is_curated`가 항상 false다.

원본은 회원 가입·로그인이 필요하다 (`내 정보 관리 → 사전 내려받기 → 전체
내려받기`, XML 25개 1.8GB, 뜻 1,210,101개). 받아서 `db/opendict/`에 풀고:

```bash
npm run db:import:open -- --dry     # 먼저 확인
npm run db:import:open             # 일반어만
npm run db:import:open -- --dialect # 방언·북한어도 인정
```

### 어휘 범주

XML의 `<type>`으로 갈린다. 파일 하나(뜻 5만 개) 기준 실제 분포는 이렇다.

| 범주 | 낱말 | 예 | 기본 |
| --- | --- | --- | --- |
| 일반어 | 6,614 | 가객·가감·가게 | **인정** |
| 방언 | 1,930 | 가가비·가걔·가겍·가골라비 | 제외 |
| 북한어 | 1,531 | 가격투쟁·가공덧살·가극무용 | 제외 |
| 옛말 | 88 | 가마괴·가야미·가히 | 제외 (항상) |

방언을 뺀 이유: "우리 동네에선 이렇게 부른다"를 받아 주려던 거였는데, 실제
데이터를 보면 대부분 지역 발음 표기(가가비·가겍)라 아무도 그렇게 타이핑하지
않는다. 판정만 어지러워진다. `--dialect`로 켤 수는 있다.

옛말은 항상 뺀다 — 지금 자판으로 칠 수 없는 옛 철자가 섞여 있다.

### 넣고 나서 생긴 일

전체 1,210,101개 뜻에서 일반어 명사 91,557개를 뽑아 새로 77,687개가 들어갔다
(나머지는 기초사전과 겹친다).

**차단 목록이 그제서야 일하기 시작했다.** 기초사전은 학습자용이라 욕설이 애초에
안 실려 있어서, 완전 차단 21개 중 사전에 실제로 있는 건 5개뿐이었다. 우리말샘에는
다 들어 있다. 인종·장애·성매매 비하어를 출제 금지에서 완전 차단으로 올렸다
(21개 → 43개, 사전에 실제로 있는 것 24개).

**뜻풀이 표시로 욕설을 찾는 건 여기서 안 통한다.** `욕으로`·`비속하게`로 훑으면
17개가 나오는데 그중 리스·잠양·탐박·탕치는 "금욕으로·탐욕으로·목욕하여"에 걸린
오탐이다. `낮추어`와 같은 함정이라, 흔한 욕설 목록을 사전에 직접 조회해 확인하는
쪽이 정확하다 (`scripts/`가 아니라 그때그때 쓰고 버리는 조회로 충분하다).

**판정이 아주 관대해졌다.** 일반어에도 가감부득·가감지인 같은 낱말이 섞여 있다.
억울함은 거의 사라지지만, 흔한 초성 조합 대부분에 답이 생겨서 어휘를 많이 아는
사람이 유리해진다. 출제 풀은 그대로 5,408개라 문제 자체는 쉬운 말만 나온다.

| | 등급 | 쓰임 |

### 범위

들어온 것은 **한국 국적 배우·가수**(`P27=Q884`, `P106`이 배우 또는 가수)와
**캐릭터** 8종 타입이다. `봉준호`는 감독이라 안 들어왔고 `피카츄`도 없다 —
포켓몬은 `전기 타입 포켓몬` 같은 별도 타입이라 캐릭터 타입 목록에 없다.
직업·타입을 더하면 넓어진다.

**영화·만화·애니는 아직 안 넣었다.** 영화는 에로 영화 제목이 섞여 있어 쿼리에서
장르 `Q599558`을 빼도 사람 검수가 더 필요하고, 만화·애니는 2~4글자 제약에
걸려 몇백 개뿐이다. 근거는 [docs/proper-noun-mode.md](../../docs/proper-noun-mode.md).

## 앞으로

- **판정 사전 넓히기 — 끝났다.** 목표 3~5만이었고 우리말샘·위키데이터를 더해
  112,792개가 됐다. 더 넓힐 이유는 당분간 없다. 방언·북한어를 인정하기로 하면
  `npm run db:import:open -- --dialect`로 다시 넣을 수 있다.
- **출제 풀 다듬기** — 아래 「힌트 난이도」 참고. 어려운 한자어가 문제일 거라
  짐작했는데, 재 보니 원인이 달랐다.

## 힌트 난이도

```bash
npm run words:hints                  # 답이 거의 없는 문제를 찾는다
npm run words:hints -- --type JUNG   # 한 타입만
npm run words:hints -- --csv         # 전부 내보내기
```

출제 단어는 **정답이 아니라 힌트를 만드는 재료**다. 플레이어는 힌트에 맞고 판정
사전에 있는 낱말이면 무엇이든 쓸 수 있다. 그래서 '금일' 같은 어려운 한자어가
출제돼도 라운드가 어려워지지 않는다 — 힌트는 `ㄱㅇ`이고 답이 수천 개다.

라운드를 망치는 건 **힌트에 맞는 답이 몇 개 없을 때**다. 답이 1개면 출제된 낱말
자신만 정답이라 사실상 그 낱말을 알아맞히라는 문제가 된다.

### 재 본 결과 (판정 사전 105,096 · 출제 풀 5,408 기준)

원인은 어휘 난이도가 아니라 **글자 수**였다.

| 힌트 | 2글자 답 중앙값 | 3글자 답 중앙값 | 3글자 중 답이 1개뿐 |
| --- | --- | --- | --- |
| 자음(CHO) | 496 | 18 | 80개 |
| 모음(JUNG) | 641 | 30 | 93개 |

초성 조합은 글자가 하나 늘 때마다 19배씩 넓어지는데 사전은 그만큼 커지지 않는다.
2글자는 넉넉하고(답 1개 사례 2건·0건) 3글자에서 무너진다.

- `가까이` 자음 `ㄱ ㄲ ㅇ` → 사전 전체에서 정답이 **가까이 하나뿐**
- `계획표` 모음 `ㅖ ㅚ ㅛ` → **계획표 하나뿐**

CHO·JUNG은 힌트 모양이 하나뿐이라 그 낱말이 뽑히면 **늘** 그 난이도가 나온다.
그렇게 늘 답 3개 이하인 낱말이 321개다.

MIX·OPEN은 사정이 다르다. 모양이 여럿이라(마스크 2ⁿ−2개, 공개 위치 n개) 나쁜
힌트가 가끔만 걸린다 — 늘 나쁜 건 MIX 1개, OPEN 0개다.

### 내린 결정 — 자음·모음을 2글자로

`LENGTH_RANGE.CHO`·`JUNG`을 `{ min: 2, max: 2 }`로 바꿨다(`src/judge/hint.js`).

후보는 셋이었다. ①2글자 제한 ②늘 나쁜 321개만 출제 풀에서 내리기 ③그대로 두기.
②를 고르지 않은 이유는, 321개를 내려도 남은 3글자 라운드가 2글자보다 27배 어려워
난이도가 들쭉날쭉한 건 그대로고, 사전을 넓힐 때마다 다시 재야 하기 때문이다.
①은 원인을 없앤다.

바꾼 뒤 다시 쟀다.

| | 전 | 후 |
| --- | --- | --- |
| 늘 답 3개 이하인 낱말 | 321개 | **6개** |
| 그중 모음(JUNG) | 162개 | **0개** |
| 자음·모음이 뽑는 출제 풀 | 4,834개 | 2,602개 |

남은 6개는 아래에 따로 적었다.

자음+모음(MIX)은 3글자를 유지했다. 마스크가 여러 개라 나쁜 힌트가 가끔만 걸리고,
늘 나쁜 낱말이 1개(`계획표`)뿐이라 2·3글자를 섞어 두는 쪽이 문제 길이의 다양성에
낫다. 한 글자 공개(OPEN)도 3~4글자 그대로다 — 늘 나쁜 낱말이 없다.

### 남은 6개

2글자로 좁힌 뒤에도 늘 답이 3개 이하인 낱말이다. 전부 쌍자음이 들어가 초성
조합이 희귀하다. 각각 사전에 실제로 어떤 답이 있는지 조회했다.

| 낱말 | 힌트 | 사전 전체의 답 | 그중 아는 말 |
| --- | --- | --- | --- |
| 꽃씨 | 자음 `ㄲ ㅆ` | 꽃씨 | **없음** |
| 큰딸 | 자음 `ㅋ ㄸ` | 큰딸 | **없음** |
| 계획표 | 자음+모음 `ㄱ ㅚ ㅛ` | 계획표 | **없음** |
| 땅콩 | 자음 `ㄸ ㅋ` | 땅콩 · 떠퀴 | **없음** |
| 한때 | 자음 `ㅎ ㄸ` | 한때 · 호떡 | 호떡 |
| 팔찌 | 자음 `ㅍ ㅉ` | 팔짱 · 팔찌 · 평찌 | 팔짱 |

「아는 말」은 **기초사전(`source='STD'`)에 있는 다른 낱말**을 뜻한다. 기초사전은
학습자용이라 어휘 등급이 붙은, 사람들이 실제로 아는 말만 담는다. `떠퀴`·`평찌`는
우리말샘에서만 나온 낱말이라 판정에서는 인정하지만 아무도 떠올려 치지 않는다.

그래서 앞의 넷은 **출제된 낱말 자신이 유일한 현실적 정답**이다. 20초 안에 그
낱말을 알아맞히라는 문제가 되어 사실상 이길 수 없다. 뒤의 둘은 아는 답이 하나
더 있지만 그래도 답 2개짜리 라운드다.

### 적용 — 여섯 개 모두 출제에서 내렸다

판정에서는 그대로 인정한다(`status='ACTIVE'` 유지). 누가 `꽃씨`를 쳤을 때 "없는
단어"라고 답하면 거짓말이 된다. 바꾸는 건 **힌트를 만드는 재료로 쓰지 않는 것**뿐이다.

낱말에는 아무 잘못이 없다 — 전부 멀쩡하고 흔한 말이다. 문제는 그 초성 조합을
가진 다른 낱말이 한국어에 거의 없다는 것이다.

**어디에 적을 것인가.** `is_curated`를 DB에서 직접 내리면 다음 `db:import` 때
되살아난다. 이 낱말들은 초급·중급이라 임포터가 다시 출제용으로 올리기 때문이다.
임포트를 견디려면 `applyBlocklist`가 읽는 목록에 있어야 한다.

다만 `NOT_SERVED`에 넣으면 안 된다. 그 목록은 "자살·마약처럼 파티 게임이 화면
한가운데 띄울 자리가 아닌 낱말"이라는 **내용 판단**이고, 여기는 **답이 없다는
계산**이다. 뜻이 다른 둘을 한 칸에 넣으면 나중에 둘 다 못 읽는다.

→ **적용함.** `blocklist.js`의 `TOO_FEW_ANSWERS`에 따로 두고
`applyBlocklist`에서 같은 방식으로 내린다.

목록은 사전이 바뀌면 다시 재야 한다. 우리말샘을 더 넣거나 방언을 인정하면 답이
늘어 풀려날 수도 있다 — `npm run words:hints`로 확인한다.
