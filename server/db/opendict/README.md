# 우리말샘 원본을 여기에 둔다

판정 사전을 넓히는 데 쓴다. 출제에는 쓰지 않는다 — 어휘 등급이 없어서
어떤 낱말이 "누구나 아는 말"인지 판단할 근거가 없다.

1. https://opendict.korean.go.kr 회원 가입 후 로그인
2. 우측 상단 `내 정보 관리` → `사전 내려받기` → `전체 내려받기` (XML)
   — 비로그인 상태에서는 이 메뉴가 보이지 않는다
3. 압축을 풀어 이 폴더에 `*.xml` 을 둔다 (26개, 약 2GB)
4. `npm run db:import:open -- --dry` 로 먼저 확인

XML 파일은 git에 올리지 않는다 (.gitignore). 이 README만 남긴다.
