# 고유명사 모드 — 출처 조사

> **조사만 했다. 아직 만들지 않았다.** 결론은 "가능하다"이고, 막힐 줄 알았던
> 데이터 출처 문제가 해소됐다는 것이 이 문서의 요지다.
>
> 조사일 2026-10-01. 라이선스와 데이터 수량은 바뀔 수 있으니 착수 전에 다시 확인한다.

## 어떤 모드인가

영화 제목·애니메이션·만화·캐릭터·배우·가수 이름 같은 **고유명사도 정답으로 인정하는**
모드다. 별도 퀴즈가 아니라 **기존 모드에 더하는** 것이다 — 힌트는 지금처럼 일반
사전에서 나오고, 답으로 칠 수 있는 낱말만 늘어난다.

그래서 라운드는 쉬워지는 방향이다. 답이 줄어드는 게 아니라 늘어난다.

### 범위를 좁히는 규칙

데이터를 넣을 때 지키는 규칙이다. 이게 있어서 표기 흔들림 문제가 작아진다.

- **2~4글자 순한글만.** 기존 제약(FR-G1)과 같다. `어벤져스엔드게임`은 애초에 안 들어온다.
- **한국어 정식 표기 하나만.** `귀멸의칼날`은 넣고 `키메츠노 야이바`는 넣지 않는다.
- **줄임말은 넣지 않는다.** `귀칼` 같은 것.
- **제목·이름 텍스트만.** 이미지·포스터·초상을 쓰지 않으므로 그쪽 권리 문제가 없다.

## 출처 비교

| 출처 | 라이선스 | 상업 이용 | 판정 |
| --- | --- | --- | --- |
| **위키데이터** | **CC0** (퍼블릭 도메인) | 가능. **출처 표시 의무도 없음** | ✅ 최적 |
| 한국어 위키백과 | CC BY-SA 4.0 | 가능 (출처 표시 + 동일조건) | ✅ 가능 |
| **나무위키** | CC BY-NC-SA 2.0 KR | **불가 — NC(비영리) 조건** | ❌ 탈락 |
| KOBIS 오픈API (영화진흥위원회) | 공공데이터. 무료 키, 심사 없음 | 데이터셋별 이용허락범위 확인 필요 | ⚠️ |
| TMDB 등 상용 영화 DB | API 이용약관 | 재배포·캐싱 제한이 통상 있음 | ⚠️ |

**나무위키는 쓸 수 없다.** 결과 화면에 광고를 넣기로 한 이상 상업적 이용이고,
NC 조건이 그것을 막는다.

**위키데이터가 압도적으로 유리하다.** CC0는 저작권을 포기한 것이라 출처 표시
의무조차 없다. 기초사전·우리말샘 때문에 이미 지고 있는 CC BY-SA의 저작자 표시·
동일조건 의무가 **더 늘지 않는다**는 뜻이다 (DICTIONARY.md 「라이선스」 참고).

## 실제로 얼마나 있나 — 실측

위키데이터 SPARQL 엔드포인트에 직접 던져 **2~4글자 순한글**만 셌다.

| 분류 | 개수 |
| --- | --- |
| 영화 제목 | **7,035** |
| 한국 배우·가수 이름 | **9,538** |

현재 출제 풀이 5,402개다. **영화 제목만으로 그보다 많다.** 한국인 이름은 대부분
3글자라 글자 수 제약과 잘 맞는다.

```sparql
# 영화 — https://query.wikidata.org/sparql?format=json&query=...
SELECT (COUNT(DISTINCT ?x) AS ?n) WHERE {
  ?x wdt:P31 wd:Q11424 ; rdfs:label ?l .
  FILTER(lang(?l) = 'ko')
  FILTER(STRLEN(?l) >= 2 && STRLEN(?l) <= 4)
  FILTER(REGEX(?l, '^[가-힣]+$'))
}

# 한국 배우·가수
SELECT (COUNT(DISTINCT ?x) AS ?n) WHERE {
  ?x wdt:P27 wd:Q884 ; wdt:P106 ?job ; rdfs:label ?l .
  VALUES ?job { wd:Q33999 wd:Q177220 }
  FILTER(lang(?l) = 'ko')
  FILTER(STRLEN(?l) >= 2 && STRLEN(?l) <= 4)
  FILTER(REGEX(?l, '^[가-힣]+$'))
}
```

### 아직 못 잰 것

애니메이션·만화·캐릭터는 **수량을 확인하지 못했다.** 직접 타입 조회로는 19·33·270개
밖에 안 잡히는데, 위키데이터에서 이것들은 하위 유형(`애니메이션 TV 시리즈` 등)으로
분류돼 있어 상위 타입을 전개하는(`wdt:P31/wdt:P279*`) 쿼리가 필요하고, 공개
엔드포인트가 그 무게를 못 견뎌 타임아웃(504)·레이트리밋(429)이 났다.

영화·인물 수준은 나올 것으로 보지만 **확인 전까지는 추정이다.** 덤프를 내려받아
로컬에서 세는 쪽이 확실하다.

## 남은 실무 문제

### 1. 중복 — 순증가분을 따로 재야 한다

7,035개 중 상당수가 이미 사전에 있다. 조회해 보니:

- `기생충` 이미 있음 (기초사전. 한자어 寄生蟲)
- `건담`·`아이유` 이미 있음 (우리말샘이 일부를 싣고 있다)
- `봉준호`·`오징어게임`·`도라에몽`·`피카츄` 없음

우리말샘이 고유명사를 **일부** 싣지만 체계적이지 않다. 실제로 몇 개가 새로
들어오는지는 넣어 보기 전에는 모른다.

### 2. 차단 목록을 새 출처에도 태워야 한다

위키데이터에는 성인물 제목도 들어 있다. 기존 `applyBlocklist`를 그대로 태우면
되지만, 빠뜨리면 사전에 공들여 만든 필터를 통째로 우회한다.

## 결정할 것 — 판정에만 넣을 것인가

"인정되는 모드"라는 말대로라면 **판정에만 추가**(`is_curated = false`)다. 힌트는
지금처럼 일반 사전에서 나오고 답만 늘어난다. 순수하게 쉬워지는 방향이고 난이도를
다시 잴 필요가 없다.

다만 그러면 `오징어게임` 같은 낱말이 **문제로 출제되지는 않는다.** 고유명사가
힌트로도 나오길 원하면 출제 풀에도 넣어야 하고, 그때는 난이도를 따로 재야 한다
(`npm run words:hints`가 그대로 쓰인다).
