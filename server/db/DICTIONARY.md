# 사전 데이터 (NFR-7)

## 출처

**국립국어원 한국어기초사전** — https://krdict.korean.go.kr

한국어 학습자용 사전이라 표제어에 **어휘 등급(초급·중급·고급)** 이 붙어 있다.
초성배틀에 이게 결정적이다. 100만 개짜리 대사전을 그대로 쓰면 힌트만 보고
아무도 못 맞히는 문제가 나오는데, 등급이 있으면 "낼 수 있는 말"과 "인정만 하는
말"을 데이터가 알아서 갈라 준다.

| 구분 | 규모 | 근거 |
| --- | --- | --- |
| 표제어 전체 | 56,555 | 원본 |
| 2~4글자 순한글 명사 | 27,408 | 아래 필터 |
| 출제용 (`is_curated`) | 5,408 | 초급·중급 + 손으로 고른 시드 |
| 완전 차단 (`status='BANNED'`) | 5 | 아래 「걸러내기」 |

### 표제어만 쓰는 이유

뜻풀이·예문·발음 음성·이미지는 **개방 대상이 아니다**. 출판물 인용이 섞여 있어
국립국어원도 재배포를 허용하지 않는다. 초성배틀에 필요한 건 "이 낱말이 사전에
있는가"뿐이라 표제어만 가져오고, 임포터도 표제어 외에는 저장하지 않는다.

## 받아서 넣기

```bash
# 1. 원본 받기 (로그인 불필요)
#    https://krdict.korean.go.kr/download/downloadPopup → 'XML 전체 내려받기'
# 2. 압축을 풀어 server/db/krdict/ 아래에 *.xml 을 둔다 (git에는 넣지 않는다)

cd server
npm run db:import -- --dry   # 무엇이 들어갈지 먼저 본다
npm run db:import            # 실제로 넣는다
npm run db:block             # 차단 목록만 다시 적용할 때
```

서버는 기동할 때 사전을 통째로 메모리에 올린다(NFR-1). 임포트 뒤에는 **서버를
다시 띄워야** 반영된다.

## 걸러내기

### 사전 → 게임

| 기준 | 결과 |
| --- | --- |
| 품사 = 명사 | 동사·형용사 기본형을 넣으면 '하다·되다·가다'가 수많은 힌트의 정답이 되어 라운드가 시시해진다 |
| 단위 = 단어 | 관용구·속담·문법 표현은 한 낱말이 아니다 |
| 2~4글자 완성형 한글 | FR-G1 |
| 등급 초급·중급 | 출제용. 고급·미지정은 판정에서만 인정한다 |

### 부적절어

사전은 말을 판단하지 않고 싣는다. 게임은 그럴 수 없다(전체 이용가, 앱인토스
검수). 다만 "곤란하다"에는 아주 다른 것들이 섞여 있다.

| | 예 | |
| --- | --- | --- |
| 낱말 자체가 욕 | 씨발·병신·개새끼 | 어떤 맥락에서도 남에게 보낼 이유가 없다 |
| 평범한데 뜻이 여럿 | 걸레·새끼·호구 | 걸레는 닦는 천이고 새끼는 동물의 아기다 |
| 중립적인데 주제가 무겁다 | 자살·마약·살인 | 뉴스와 교과서에 나오는 서술어다 |

한 칸에 몰아넣으면 멀쩡한 낱말이 사전에서 사라진다. 그래서 두 단계로 나눈다.

**출제 금지** (`is_curated = false`, 판정은 인정) — 대부분이 여기 온다.

- 사전이 뜻풀이에 `낮잡아`·`비속하게` 표시를 달아 둔 낱말 (295개, 출제 풀에서
  15개). 귀머거리·장님·바보처럼 이미 차별어로 표시된 말은 여기서 자동으로
  걸러지므로 손 목록에 따로 적지 않는다.
- `src/words/blocklist.js`의 `NOT_SERVED` — 자살·마약·성범죄처럼 사전이 아무
  표시도 달지 않는 것들. 낱말에 죄가 있는 게 아니라 파티 게임이 화면 한가운데
  띄우고 다 같이 맞힐 자리가 아니라는 뜻이다.

**완전 차단** (`status = 'BANNED'`, 출제·판정 모두 제외) — 아주 좁게 쓴다.

판정에서 인정하면 그 낱말이 정답 바에 실려 **방 전체 화면에 뜬다**(`round.won`).
즉 판정 인정은 곧 노출이고, 채팅이 없는 이 게임에서 욕설을 남에게 보낼 수 있는
유일한 통로가 된다. 그 통로를 막는 게 이 목록의 전부다. 노골적 욕설과 성기 속어
21개뿐이고, 그중 학습자 사전에 실제로 있는 건 5개다.

반대로 **사전에 있는 말을 판정에서 빼면 안 된다.** "없는 단어"라고 답하는 셈이라
대놓고 거짓말이고, 억울함을 막자고 판정 사전을 관대하게 만든 취지에도 어긋난다.

목록에서 뺀 낱말은 `npm run db:block`을 다시 돌리면 되살아난다. 신고로 막은
낱말(`source='REPORT'`)은 되살리지 않는다 — 사람이 보고 막은 것을 목록이
되돌리면 안 된다.

이 목록이 완전할 수는 없다. 놓친 말은 단어 신고(`word_reports`)로 받아 옮기는
게 원래 설계다(FR-W2).

## 우리말샘 (판정 전용)

**국립국어원 우리말샘** — https://opendict.korean.go.kr · 표제어 110만 · 같은
CC BY-SA 2.0 KR

기초사전과 역할이 다르다.

| | 등급 | 쓰임 |
| --- | --- | --- |
| 한국어기초사전 | 초급·중급·고급 | **출제** + 판정 |
| 우리말샘 | 없음 | **판정만** |

우리말샘은 전수 대사전이라 어휘 등급이 없다. 어떤 낱말이 "누구나 아는 말"인지
판단할 근거가 없으니 출제 풀에 넣을 수 없고, 넣으면 힌트만 보고 아무도 못 맞히는
문제가 나온다. 그래서 여기서 들어오는 낱말은 `is_curated`가 항상 false다.

원본은 회원 가입·로그인이 필요하다 (`내 정보 관리 → 사전 내려받기 → 전체
내려받기`, XML 약 2GB). 받아서 `db/opendict/`에 풀고:

```bash
npm run db:import:open -- --dry     # 먼저 확인
npm run db:import:open             # 일반어만
npm run db:import:open -- --dialect # 방언·북한어도 인정
```

### 어휘 범주

XML의 `<type>`으로 갈린다. 파일 하나(뜻 5만 개) 기준 실제 분포는 이렇다.

| 범주 | 낱말 | 예 | 기본 |
| --- | --- | --- | --- |
| 일반어 | 6,614 | 가객·가감·가게 | **인정** |
| 방언 | 1,930 | 가가비·가걔·가겍·가골라비 | 제외 |
| 북한어 | 1,531 | 가격투쟁·가공덧살·가극무용 | 제외 |
| 옛말 | 88 | 가마괴·가야미·가히 | 제외 (항상) |

방언을 뺀 이유: "우리 동네에선 이렇게 부른다"를 받아 주려던 거였는데, 실제
데이터를 보면 대부분 지역 발음 표기(가가비·가겍)라 아무도 그렇게 타이핑하지
않는다. 판정만 어지러워진다. `--dialect`로 켤 수는 있다.

옛말은 항상 뺀다 — 지금 자판으로 칠 수 없는 옛 철자가 섞여 있다.

### 넣기 전에 알아둘 것

- **판정이 아주 관대해진다.** 일반어에도 가감부득·가감지인·가거지지 같은 낱말이
  섞여 있다. 억울함은 사라지지만, 2글자 초성 조합 대부분에 답이 생겨서 "모두
  패스"가 거의 나오지 않게 된다.
- **차단 목록이 그제서야 일한다.** 지금 완전 차단 21개 중 사전에 실제로 있는 건
  5개뿐이다 — 학습자 사전이라 애초에 욕설이 안 실려 있어서다. 110만 표제어에는
  다 들어 있으므로, 넣은 뒤 정답 바에 떠서는 안 될 낱말을 다시 훑어야 한다.
  임포터가 끝에 `applyBlocklist`를 자동으로 돌리지만 목록 자체를 넓혀야 한다.
