# 사전 데이터 (NFR-7)

## 출처

**국립국어원 한국어기초사전** — https://krdict.korean.go.kr

한국어 학습자용 사전이라 표제어에 **어휘 등급(초급·중급·고급)** 이 붙어 있다.
초성배틀에 이게 결정적이다. 100만 개짜리 대사전을 그대로 쓰면 힌트만 보고
아무도 못 맞히는 문제가 나오는데, 등급이 있으면 "낼 수 있는 말"과 "인정만 하는
말"을 데이터가 알아서 갈라 준다.

| 구분 | 규모 | 근거 |
| --- | --- | --- |
| 표제어 전체 | 56,555 | 원본 |
| 2~4글자 순한글 명사 | 27,408 | 아래 필터 |
| 출제용 (`is_curated`) | 5,406 | 초급·중급 + 손으로 고른 시드 |
| 차단 (`status='BANNED'`) | 86 | 아래 「걸러내기」 |

  SA 의무가 발동하지 않지만, 앱 번들에 단어 파일을 넣어 배포하기로 하면 그
  파일에 CC BY-SA를 붙여야 한다.

### 표제어만 쓰는 이유

뜻풀이·예문·발음 음성·이미지는 **개방 대상이 아니다**. 출판물 인용이 섞여 있어
국립국어원도 재배포를 허용하지 않는다. 초성배틀에 필요한 건 "이 낱말이 사전에
있는가"뿐이라 표제어만 가져오고, 임포터도 표제어 외에는 저장하지 않는다.

## 받아서 넣기

```bash
# 1. 원본 받기 (로그인 불필요)
#    https://krdict.korean.go.kr/download/downloadPopup → 'XML 전체 내려받기'
# 2. 압축을 풀어 server/db/krdict/ 아래에 *.xml 을 둔다 (git에는 넣지 않는다)

cd server
npm run db:import -- --dry   # 무엇이 들어갈지 먼저 본다
npm run db:import            # 실제로 넣는다
npm run db:block             # 차단 목록만 다시 적용할 때
```

서버는 기동할 때 사전을 통째로 메모리에 올린다(NFR-1). 임포트 뒤에는 **서버를
다시 띄워야** 반영된다.

## 걸러내기

### 사전 → 게임

| 기준 | 결과 |
| --- | --- |
| 품사 = 명사 | 동사·형용사 기본형을 넣으면 '하다·되다·가다'가 수많은 힌트의 정답이 되어 라운드가 시시해진다 |
| 단위 = 단어 | 관용구·속담·문법 표현은 한 낱말이 아니다 |
| 2~4글자 완성형 한글 | FR-G1 |
| 등급 초급·중급 | 출제용. 고급·미지정은 판정에서만 인정한다 |

### 부적절어

사전은 말을 판단하지 않고 싣는다. 게임은 그럴 수 없다(전체 이용가, 앱인토스
검수). 두 단계로 나눈다 — 한 단계로 묶으면 어느 쪽이든 손해가 크다.

**출제 금지** (`is_curated = false`, 판정은 인정)
뜻풀이에 `낮잡아`·`비속하게` 같은 표시가 붙은 낱말. 사전이 직접 달아 둔
표시라 따로 만든 욕설 목록보다 훨씬 넓게 잡힌다(295개, 출제 풀에서는 15개).
'봉사'·'콧잔등'처럼 동음이의어 때문에 함께 빠지는 멀쩡한 말이 있지만, 판정까지
막지는 않으므로 친 사람이 억울할 일은 없다.

**완전 차단** (`status = 'BANNED'`, 출제·판정 모두 제외)
`src/words/blocklist.js`의 손으로 만든 목록. 자살·마약·성범죄처럼 낱말 자체는
중립적인 서술어라 사전이 아무 표시도 달지 않는 것들이다.

이 목록이 완전할 수는 없다. 놓친 말은 단어 신고(`word_reports`)로 받아 BANNED로
옮기는 게 원래 설계다(FR-W2).

## 앞으로

- **판정 사전 넓히기** — 목표는 3~5만인데 지금 27,328개다. 우리말샘
  (https://opendict.korean.go.kr, 표제어 110만, 같은 CC BY-SA 2.0 KR)을 더하면
  넉넉히 넘는다. 회원 가입 후 `내 정보 관리 → 사전 내려받기 → 전체 내려받기`.
  `words.source`에 `OPEN_DICT` 값이 이미 있다.
- **출제 풀 다듬기** — 초급·중급이라도 '금일'·'여부'처럼 힌트만 보고 떠올리기
  어려운 한자어가 섞여 있다. 실제 라운드에서 아무도 못 맞힌 단어를
  `submissions`로 추적해 내리는 게 다음 단계다.
