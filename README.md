# 초성배틀 (Choseong Battle)

> 먼저 외치면 이기는 한글 초성 퀴즈

한글 자모 힌트를 보고 사전에 있는 단어를 **가장 먼저** 입력하는 사람이 이기는 2~4인 실시간 멀티플레이 퀴즈 게임입니다. 토스 미니앱(앱인토스) 출시를 목표로 개발 중입니다.

```
   ㄱ  ㅈ   →  감자 · 기적 · 간장 · 과자 …
   ㅏ  ㅓ   →  사전 · 감정 · 발전 …
  ⬜ 장 ⬜  →  화장품 · 소장품 …
```

친구들끼리 입으로 하던 초성 게임("ㄱㅈ! 되는 말 아무거나 먼저 외쳐!")을 그대로 옮긴 룰이라 설명이 거의 필요 없습니다.

## 핵심 규칙

### 문제 카테고리 5종

| 카테고리 | 힌트 | 정답 예시 | 글자 수 |
|---|---|---|---|
| 자음 | `ㄱ ㅈ` | 감자, 기적, 간장 | 2~3 |
| 모음 | `ㅏ ㅓ` | 사전, 감정, 발전 | 2~3 |
| 자음+모음 | `ㄹ ㅔ` | 라테, 로켓 | 2~3 |
| 한 글자 공개 | `⬜ 장 ⬜` | 화장품 | 3~4 |
| 종합 | 위 네 가지 혼합 | | 2~4 |

- **자음+모음**은 글자마다 초성 또는 중성 중 하나를 무작위로 제시합니다. (라테 → 1글자째 초성 `ㄹ`, 2글자째 중성 `ㅔ`)
- 같은 카테고리를 선택한 유저끼리 매칭됩니다.

### 라운드 진행 — 선착순

1. 문제 공개와 함께 제한시간 20초 카운트다운
2. 전원 동시 입력 경쟁 → **가장 먼저 유효한 정답을 낸 사람이 라운드 승리**
3. 아무도 못 맞히면 **라운드 번호는 유지하고 문제만 교체** — 모든 라운드는 승자가 나와야 넘어갑니다
4. 설정한 라운드 수를 마치면 종료 (기본 10, 최대 20)

### 점수 — 라운드 승수제

라운드를 먼저 맞히면 1점. 보너스·콤보·감점은 없습니다. 최종 결과는 `6 : 4` 형태의 승수 스코어로 표시됩니다.

동점일 때는 1위 동점만 서든데스 1라운드로 가리고, 그 외 순위는 평균 정답 속도가 빠른 쪽이 상위입니다.

### 정답 판정 — 사전 판정

**힌트 패턴과 일치하고 판정용 사전에 존재하는 단어면 전부 정답입니다.** 주제 제한은 없습니다.

```
힌트 ㄱㅈ  →  감자 ✅  간장 ✅  과자 ✅  기적 ✅  …
```

- 한글 표기만 인정합니다. 알파벳·숫자·특수문자는 입력 단계에서 차단됩니다.
- 사전에 등재된 외래어(라테, 버스)는 인정하되 영어 음차 표현(나이스, 굿)은 인정하지 않습니다.
- 미인정 단어는 **제출 자체가 성립하지 않습니다.** 흔들림 애니메이션과 "등록되지 않은 단어" 피드백 후 즉시 재입력할 수 있으며, 감점이나 입력 잠금은 없습니다.
- 판정·타이머·선착 순위·점수 계산은 **전부 서버에서** 수행합니다.

## 게임 모드

| | 빠른 대전 | 친구 방 | 혼자 연습 | 랭크전 `v1.1` |
|---|---|---|---|---|
| 인원 | 2~4인 | 2~4인 | 1인 | 1대1 고정 |
| 카테고리 | 5종 선택 | 방장 설정 | 5종 선택 | 종합 고정 |
| 라운드 | 10 | 5~20 | 무제한 | 10 고정 |
| 랭킹 반영 | 주간 랭킹 | ❌ | ❌ | 시즌 티어 |

### 친구 방

방 이름, 문제 수(5~20), 카테고리, 비밀번호(선택)를 설정해 방을 만듭니다. 공개 방 목록에 노출되며, 초대 코드나 토스 공유 링크로 입장할 수 있습니다. 링크로 들어오면 비밀번호를 묻지 않습니다.

### 혼자 연습 — 5단계

| 단계 | 제한시간 | 방식 |
|---|---|---|
| 자유 | 무제한 | 패스 가능, 종료 없음 |
| 초보 | 12초 | 연속 도전 |
| 중수 | 8초 | 연속 도전 |
| 고수 | 5초 | 연속 도전 |
| 초고수 | 3초 | 연속 도전 |

시간제 단계는 오답 또는 시간 초과 시 종료되며, 단계·카테고리별 최고 연속 기록이 저장됩니다.

### 랭크전 `v1.1`

1대1 고정, 종합 카테고리 고정, 10라운드. 네 유형을 균등 배분한 뒤 순서만 섞어 출제해 유형 운을 제거합니다.

- 표준 Elo — 시작 1000점, K=32 (초반 10판은 K=64)
- 5판 배치 후 티어 부여: 브론즈 / 실버 / 골드 / 플래티넘 / 다이아 (+ 상위 100인 랭커)
- 시즌 6~8주, 종료 시 소프트 리셋

> 레이팅·시즌 관련 DB 필드는 MVP 스키마에 미리 포함해 이후 마이그레이션 부담을 줄입니다.

## 랭킹

주간 랭킹의 지표는 **주간 라운드 승수 합산**이며 단위는 "승"입니다.

| 항목 | 규칙 |
|---|---|
| 집계 대상 | 빠른 대전만 (친구 방 제외) |
| 상한 | 주간 상위 20판까지만 집계 |
| 등재 조건 | 주간 3판 이상 플레이 |
| 동점 | 평균 정답 속도가 빠른 쪽이 상위 |
| 리셋 | 매주 월요일 00:00 KST |

<details>
<summary>왜 친구 방을 제외하고 20판 상한을 두는가</summary>

- **담합 차단** — 친구 둘이 2인 비밀번호 방을 파고 한 명이 계속 져주면 승수를 무제한으로 확보할 수 있습니다. 외부에서 보이지 않아 탐지도 어렵습니다.
- **갈아넣기 완화** — 단순 합산은 실력이 아니라 플레이 시간을 측정합니다. 20판 상한은 초반 동기를 남기면서 무제한 누적을 막습니다.
- **인원수 보정은 보류** — 2인 판의 라운드 승리 기대 확률은 50%, 4인 판은 25%입니다. 보정이 계산상 타당하지만 소수점 점수는 납득이 어려워, 매칭이 3~4인으로 채워지는지 확인 후 재검토합니다.

</details>

## 아바타

한복(저고리)을 입은 동물 캐릭터 8종입니다. 완성된 이미지를 그대로 쓰고, 커스터마이징은 **소품 레이어를 겹쳐** 표현합니다.

```
호랑이 · 곰 · 토끼 · 고양이 · 강아지 · 너구리 · 판다 · 원숭이
```

사람이 아닌 동물을 택한 이유는 세 가지입니다. 32px 스코어보드에서 **귀 실루엣만으로 식별**되고, 피부색 선택지 부담이 없으며, 동물 이름이 실제 문제로 출제되어 콘텐츠와 이어집니다.

### 커스터마이징

| 슬롯 | MVP | 확장 예정 |
|---|---|---|
| 머리 | 갓 6종 (+ 없음) | 비니 · 왕관 · 리본 |
| 얼굴 | — | 안경 6종 |
| 목 | — | 목도리 · 노리개 |
| 배경 | 단색 6종 + 계절 4종 | 시즌 배경 |

모든 아이템은 **무료**이며 승수 달성·연속 정답 기록·친구 초대로 해금됩니다. 외형 전용이라 승패에 영향을 주지 않습니다.

### 에셋 파이프라인

원본 이미지는 캔버스 비율과 캐릭터 크기가 제각각이므로(원본에서 캐릭터가 차지한 높이 비율 65~92%) 스크립트로 일괄 정규화합니다.

| 항목 | 값 |
|---|---|
| 캔버스 | 1024 × 1024, 투명 배경 PNG |
| 검출 | 알파 채널 바운딩 박스 |
| 가로 | 캔버스 폭의 70% |
| 하단 여백 | 6% |
| 머리 위 여백 | 16% (갓 착용 공간) |
| 배율 | 폭 기준과 높이 상한 중 작은 값 (잘림 방지) |

```bash
python scripts/normalize_avatars.py
```

동물별 보정값이 필요합니다. 토끼는 귀 때문에 자동 규칙만으로는 얼굴이 작아져 `1.38`을 적용합니다.

| 동물 | 보정 | 동물 | 보정 |
|---|---|---|---|
| 토끼 | 1.38 | 호랑이 · 너구리 | 1.00 |
| 곰 | 1.05 | 판다 · 원숭이 | 0.98 |
| | | 고양이 · 강아지 | 0.95 |

### 표시 크기

| 용도 | 크기 |
|---|---|
| 게임 중 스코어보드, 랭킹 리스트 | 32px (얼굴 크롭 버전) |
| 대기방 슬롯, 결과 순위 | 48px |
| 홈 프로필, 랭킹 포디엄 1위 | 64px |
| 마이페이지, 승리 연출 | 80px |

> **소품 에셋은 원본 그대로 쓸 수 없습니다.** 갓은 턱끈과 구슬 장식이 얼굴 정중앙을 덮으므로 상단 약 52%(모자 본체)만 잘라 사용합니다. 앞으로 소품을 생성할 때는 프롬프트에 "끈·늘어지는 장식 없이 본체만" 조건을 넣으세요.

## 아키텍처

```
[토스 앱]
  └ 미니앱 클라이언트 (React)
        │  wss://  실시간 게임
        │  https:// 로그인 · 전적 · 랭킹
        ▼
  게임 서버 (NestJS + Socket.IO)
        ├ Redis      매칭 큐 · 룸 상태 · 선착 락 · pub/sub
        └ PostgreSQL 유저 · 전적 · 단어 · 랭킹
```

### 설계 원칙

- **서버 권위** — 타이머·판정·선착 순위(서버 수신 시각)·점수는 전부 서버 기준. 클라이언트는 입력만 전송합니다.
- **판정 엔진 2종 분리** — ① 패턴+사전 판정(현재) ② 지정 정답 판정(향후 상식·국기 퀴즈용). 문제 데이터에 판정 타입 필드를 둬 방·매칭·점수 시스템을 재사용합니다.
- **플랫폼 독립** — 토스 SDK 의존부(로그인·공유·광고)는 어댑터 계층으로 분리해 추후 이식을 쉽게 합니다.
- **재접속 복구** — 룸 상태를 Redis에 보관, 30초 내 재접속 시 진행 중 게임에 복귀시킵니다.
- **어뷰징 감지** — 문제 공개 후 0.5초 미만 정답 등 비정상 패턴을 로깅·제재합니다.

### 선착 판정 시퀀스

```
Client                Server              Redis         Dictionary
  │  round.submit       │                   │                │
  ├────────────────────▶│                   │                │
  │                     │ 한글 검사·자모 분해·패턴 대조        │
  │                     ├──────────────────────────────────▶ │
  │                     │◀────────────────────────── 등재 O(1)│
  │                     │  SETNX round:winner │               │
  │                     ├──────────────────▶│                │
  │  round.won (전체 브로드캐스트)            │                │
  │◀────────────────────┤                   │                │
```

락을 얻지 못하면 `submit.rejected { ROUND_CLOSED }`가 본인에게만 전송됩니다.

## 단어 데이터

2단 구조로 관리합니다.

| 구분 | 규모 | 용도 |
|---|---|---|
| 출제용 큐레이션 | 3,000~5,000개 | 실제 문제로 나가는 단어 |
| 판정용 사전 | 10만 단어 이상 목표 | 정답 인정 여부 판단 |

- 판정용 사전은 서버 기동 시 메모리 해시셋으로 올려 제출당 **O(1)** 조회합니다.
- `words` 테이블에 초성열·중성열을 미리 계산해 저장하고, 패턴 역인덱스로 활용합니다.
- 게임 중 **단어 신고** 버튼으로 추가·삭제 요청을 접수합니다. 신고분과 `NOT_IN_DICT`로 거절된 제출 로그를 주 1회 배치 검수합니다(LLM 1차 필터 → 사람 최종 승인).
- **런타임 LLM 호출은 금지합니다.** 속도·공정성·비용 문제로, LLM은 오프라인 배치에서만 사용합니다.

## 디자인

웜 팔레트 + 한복 동물 캐릭터. 토스 기본 UI(파랑·화이트)와 색이 겹치지 않아 미니앱 안에서 묻히지 않습니다.

| 역할 | 색 |
|---|---|
| 배경 | `#F3E9DC` 웜 크림 |
| 카드 | `#FFFCF7` 오프화이트 |
| 텍스트 | `#3B2F27` 잉크 · `#6E5B4C` 보조 · `#93806F` 흐림 |
| 메인 액션 · 자음 | `#C4622D` 테라코타 (그림자 `#96461C`) |
| 자음+모음 · 성공 | `#7A9471` 세이지 (그림자 `#5A7152`) |
| 모음 · 강조 | `#D9A036` 머스타드 (그림자 `#AE7A1B`) |
| 빈칸 · 비활성 | `#E6D6C0` 모래 (테두리 `#C6B096`) |

- **색 의미 체계** — 자음 = 테라코타, 모음 = 머스타드, 자음+모음 = 세이지, 한 글자 공개 = 잉크, 빈칸 = 모래. 같은 자모 유형은 어느 화면에서든 같은 색을 씁니다.
- 3D 입체 버튼(`box-shadow: 0 4px 0 <어두운색>`)으로 캐주얼 게임 특유의 촉감을 유지합니다.
- 폰트는 Pretendard(UI)와 Jua(타이틀). 모두 무료 라이선스입니다.

게임 화면에는 **2벌식 한글 키보드**를 자체 구현했습니다(도깨비불·복합모음·복합종성·쌍자음 처리 포함). PC에서는 물리 키보드 QWERTY 매핑도 동작합니다.

## 배포

### 앱인토스 파이프라인

```bash
npm run build          # <서비스명>.ait 번들 생성
npx ait deploy         # CI/CD 업로드 (SDK v1.4.0+, API 키 필요)
```

`.ait` 업로드 → QR 테스트(최소 1회 필수) → 검토 요청 → 승인 → 출시

- 앱 정보 검토 1~2영업일, 번들 검토 최대 3영업일, **게임 카테고리는 7영업일 이상 소요 가능**
- 출시·롤백 모두 전체 사용자에게 즉시 반영됩니다
- 테스트 스킴은 `intoss-private://` + `_deploymentId`. `intoss://`는 출시 후에만 동작하므로 **초대 링크 딥링크는 출시 전 실스킴 검증이 불가능**합니다

### 서버 CORS 허용 목록 (SDK 3.x)

```
https://<appName>.web.tossmini.com          실서비스
https://<appName>.private-web.tossmini.com  QR 테스트
```

### 플랫폼 제약

| 항목 | 내용 |
|---|---|
| 사용 연령 | 만 19세 이상만 이용 가능 |
| 번들 | 압축 해제 기준 100MB 이하 |
| 렌더링 | CSR / SSG만 가능 (SSR 금지) |
| WebSocket | `wss://` 암호화 연결만 허용 |
| 보안 | `eval` 등 외부 코드 실행 금지, history 조작 금지 |
| 성능 | 최초 화면까지 10초 이내, 인터랙션 지연 2초 미만 |
| 사운드 | On/Off 설정 필수, 백그라운드 전환 시 즉시 종료·복귀 시 재생 |
| 화면 | 인게임 풀스크린, Safe Area(Dynamic Island 포함) 미침범, 종료 시 확인 모달 |
| 광고 | 인트로·로딩·컷신·팝업 모달 등 일시적 화면 노출 금지, 사전 프리로드 필수 |

> 광고는 **결과 화면 진입 시점 1회**만 노출합니다. 매칭 대기·라운드 전환·승리 연출은 모두 "일시적 화면"에 해당해 광고를 넣을 수 없습니다. 로드 실패 시에는 광고를 건너뛰고 결과 화면으로 진행해 게임 흐름을 막지 않습니다.

### 게임 등급분류

게임 앱은 등급 심의 증빙 제출이 **의무**입니다. 미이행 시 시정 권고·수사 의뢰·행정처분 대상이 됩니다.

| 경로 | 내용 |
|---|---|
| 오픈마켓 선출시 | 구글 플레이·앱스토어·원스토어 등에 먼저 출시해 자체등급분류 획득 |
| 게임물관리위원회 직접 심의 | 등급분류증명서를 PDF로 제출 |

본 프로젝트는 **직접 심의**를 택합니다. 오픈마켓 경로는 등급분류를 받기 위해 앱을 하나 더 만들어야 하고, 두 버전이 동일 게임임을 플레이 화면 각 2장으로 증명해야 하는 부담이 있습니다.

예상 등급은 **전체이용가**입니다. 내용정보 7개 항목 중 선정성·폭력성·공포·약물·범죄·사행성은 해당 없으며, 현금성 보상·확률형 아이템도 없습니다. 다만 유저 닉네임이 랭킹에 공개 노출되므로 **비속어 필터가 필요**합니다(언어의 부적절성 항목 대응).

> 게임 이용등급과 플랫폼 연령 제한은 별개입니다. 게임이 전체이용가여도 앱인토스는 만 19세 이상에게만 제공됩니다.
